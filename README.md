# WEBINFOSOLUTION Premium Website

React + Vite multi-page agency website with React Router, Framer Motion, React Icons and pure CSS.

## Run
```bash
npm install
npm run dev
```

## Logo replacement
The repository includes `src/assets/logos/webinfosolution-logo.svg` as a temporary placeholder because the official logo file was not available in the build workspace. Replace that file with the official logo (or update imports in Header/Footer) without changing the site layout.

## Contact details
Edit `src/data/contact.js` once. Phone and WhatsApp buttons use that single config.

## Dummy imagery
All dummy visuals are local `.webp` files under `src/assets/images/` and can be replaced without layout changes.
